Supported hardware and wiring

This firmware targets the ESP32-C3 only; other ESP32 family chips are not supported by this release. The board bridges USB Serial/JTAG on one side and a hardware UART on the other, so a target MCU with 3.3 V logic UART pins can be programmed and monitored over the same USB cable used to flash the ESP32-C3.

Connect only 3.3 V logic-level UART signals; do not connect RS-232 or 5 V logic directly.

First-time setup

  1. Flash the firmware using the web installer below, or with idf.py flash from source.
  2. On first boot (or whenever no Wi-Fi network is saved), the device starts an open setup access point named UniSerial-xxxxxx.
  3. Connect a computer or phone to that access point and open http://192.168.4.1 in a browser to reach the configuration page.
  4. Select and save a Wi-Fi network. After a successful connection, the same configuration page is reachable at the device's DHCP address on your router's network; find it in the router's client list.
  5. If the saved network cannot be reached, the device automatically falls back to the open setup access point so it is never left unreachable.

UART and Wi-Fi configuration

All configuration is done through the web portal; there is no serial configuration protocol. The following UART parameters are stored in NVS and applied after the device restarts:

  • Baud rate
  • Data bits, parity, and stop bits
  • Buffer size
  • RX/TX signal inversion

Wi-Fi password field behavior: leaving the password field blank when saving preserves the currently stored Wi-Fi password. To remove a saved password (for example to configure an open network), use the explicit "clear password" checkbox on the configuration page; only that explicit action clears the stored credential.

The ESP32-C3 USB Serial/JTAG hardware ignores the host's USB CDC line-coding baud value, so a host terminal cannot change the UART baud rate; the baud rate must be set from the web configuration page.

USB and Telnet transport modes

USB Serial/JTAG and the optional Telnet UART bridge are mutually exclusive for UART data forwarding:

  • By default, the Telnet bridge is disabled and all UART traffic is forwarded over USB Serial/JTAG to the host computer.
  • When Telnet is enabled from the configuration page, it replaces USB Serial/JTAG for UART data forwarding. USB remains available for flashing only: this release disables the secondary USB console and reassigns the UART0 pins, so firmware log/system-message output is not exposed over USB whether or not Telnet is active.
  • Only one Telnet client can connect at a time; UART output received without an authenticated Telnet client connected is discarded rather than replayed later.

Enable or disable Telnet, and set its port (any value from 1 to 65535 except 80, which is reserved for the configuration page), from the web configuration page. Changes take effect after the device restarts.

Status LED (connection and activity)

The onboard status LED on GPIO8 indicates connection and data-activity state: it reflects whether a client (USB host or Telnet) is connected, and blinks on UART traffic.

Hardware limitation: on this board, GPIO8 is also wired as the external-target BOOT0 control line. The status LED and external-target BOOT0 control cannot operate at the same time: while the status LED is active, GPIO8 must not be used to drive an external target's boot mode, and vice versa. Do not rely on GPIO8 for BOOT0 control if you need the status LED, and do not expect LED activity while GPIO8 is being used for BOOT0 control.

Security notes

  • Unencrypted traffic: the Telnet UART bridge and the device's own configuration page are served without encryption. Credentials saved for Telnet are stored in unencrypted NVS on the device.
  • Open setup network: the initial setup access point is open (no Wi-Fi password) and the configuration page itself has no login.
  • Use the Telnet bridge and the configuration page only on trusted local networks. Neither is suitable for exposure to untrusted networks or the public internet.
  • Telnet authentication is optional: leave the Telnet password empty for no login, or set both a username and password to require one.

Troubleshooting and recovery

  • If the saved Wi-Fi network is unreachable, the device automatically falls back to the open UniSerial-xxxxxx setup access point at http://192.168.4.1.
  • If the configuration page is unreachable after a Wi-Fi change, check your router's client list for the device's new DHCP address, or reconnect to the setup access point.

Every install clears saved settings: every Web Flasher install clears saved Wi-Fi/UART settings, regardless of whether you accept or decline the installer's "Erase device" prompt. Erasing removes your saved Wi-Fi and UART configuration settings from NVS in addition to the firmware itself; so does a normal (non-erase) install, since this release ships a single merged image written starting at flash offset 0 that spans the NVS region. Save your Wi-Fi and UART settings before installing, and reconfigure the device afterward.

Install firmware from your browser

Requirements: this installer uses the Web Serial API, which requires a Chromium-based browser (Chrome or Edge) served over HTTPS (or localhost) and a direct USB connection to the ESP32-C3. Web Serial is not available in Firefox or Safari, and it is not available over a plain HTTP connection.

Connect the ESP32-C3 over USB, then click Connect and choose the matching serial port.

Your browser does not support the Web Serial API. Use Chrome or Edge over HTTPS. Web Serial access is not permitted on this page. Reload over HTTPS and try again.
